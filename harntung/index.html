ขั้นตอนการเชื่อมต่อ Firebase

ทำตาม 4 ขั้นตอนง่ายๆ เพื่อเปิดใช้งานระบบ Real-time:

  1. ไปที่เว็บไซต์ Firebase Console แล้วกดสร้างโปรเจกต์ใหม่ (Create a project)
  2. เปิดใช้งาน Authentication:
    ไปที่เมนู Build > Authentication > Sign-in method แล้วเปิดใช้งาน Email/Password
  3. เปิดใช้งาน Cloud Firestore Database:
    ไปที่เมนู Build > Firestore Database > กด Create database > ไปที่แท็บ Rules แล้วใส่กฎให้อนุญาตอ่านเขียน: allow read, write: if request.auth != null;
  4. นำ Config มาใส่ในโค้ด:
    ไปที่ Project Settings > General > Your apps > Web (</>) คัดลอกค่า firebaseConfig มาวางแทนที่ในไฟล์ index.html (บรรทัดที่ 618-626)
