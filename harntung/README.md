# 💸 Harntung (ระบบหารตังค์) - Real-time Edition

เว็บแอปพลิเคชันคำนวณและหารค่าใช้จ่ายกับเพื่อนแบบ **Real-time** พร้อมระบบสมาชิก, ระบบกลุ่มทริป, เชิญเพื่อนด้วยอีเมล, อัปโหลด QR Code รับเงิน และบันทึกโน้ตเลขบัญชี

---

## ✨ ฟีเจอร์ที่ได้รับการอัปเกรด

1. **ระบบฐานข้อมูลและการซิงก์แบบ Real-time (Firebase Cloud Firestore):**
   - เมื่อมีการเพิ่มเพื่อน, บันทึกค่าใช้จ่าย, ลบรายการ, แก้ไขชื่อทริป, บันทึกโน้ต หรือเปลี่ยนรูป QR Code ข้อมูลจะอัปเดตไปยังหน้าจอของเพื่อนทุกคนในทริปพร้อมกันทันทีโดยไม่ต้องกดรีเฟรชหน้าเว็บ
   - รองรับการมีหลายทริปและสลับทริปได้ทันทีผ่านเมนูด้านบน

2. **ระบบเชิญเพื่อนด้วยอีเมล & สถานะสมาชิก (แท็บ 1):**
   - สามารถกรอก **อีเมลของเพื่อน** เพื่อเชิญเข้าร่วมทริปได้ทันที
   - ระบบจะค้นหาบัญชีที่ลงทะเบียนไว้ในระบบ และดึงชื่อมาแสดงให้อัตโนมัติ
   - แสดงสถานะชัดเจนระหว่าง **👑 ผู้สร้างบิล (Admin)** และ **สมาชิก**
   - เมื่อเพื่อนล็อกอินเข้ามาด้วยอีเมลที่ถูกเชิญ จะมองเห็นทริปนี้และเข้ามาร่วมจัดการบิลได้ทันที

3. **ระบบโน้ต & อัปโหลด QR Code รับเงิน (แท็บ 3):**
   - **ผู้สร้างบิล (Admin)** สามารถพิมพ์ข้อความโน้ต (เช่น ธนาคาร, เลขบัญชี, พร้อมเพย์) และกดบันทึกแบบ Real-time
   - มีปุ่ม **คัดลอกข้อความ (Copy)** ให้เพื่อนๆ กดคัดลอกเลขบัญชีไปโอนเงินได้สะดวกรวดเร็ว
   - **อัปโหลดรูปภาพ QR Code รับเงิน**: ระบบจะทำการบีบอัดรูปภาพอัตโนมัติด้วย HTML5 Canvas แปลงเป็น Base64 ขนาดเล็กกะทัดรัด (~20-30 KB) บันทึกลง Firestore ได้ทันทีโดยไม่ต้องตั้งค่า Firebase Storage เพิ่มเติม
   - สมาชิกทุกคนสามารถกดคลิกเพื่อดูรูป QR Code ขยายใหญ่เพื่อสแกนจ่ายเงินได้ง่ายๆ

4. **ระบบแนบสลิปการโอนเงิน (Payment Slip) แบบ Real-time (แท็บ 3):**
   - สมาชิกที่มีรายการต้องโอนเงิน สามารถกดปุ่ม **"แนบสลิป"** จากเครื่องได้ทันที
   - ระบบบีบอัดภาพด้วย HTML5 Canvas (ความกว้างไม่เกิน 600px และบีบอัด JPEG) บันทึก Base64 ลง Firestore Real-time พร้อมเวลาที่อัปโหลด
   - สมาชิกทุกคนสามารถกด **"ดูสลิป"** เปิด Modal เพื่อตรวจสอบรูปสลิปขนาดใหญ่
   - **ผู้สร้างบิล (Admin)** สามารถกด **"ยืนยันรับเงินแล้ว"** เพื่อเปลี่ยนสถานะเป็นสีเขียว หรือกด **"ลบสลิป/ให้ส่งใหม่"** ในกรณีที่สลิปไม่ถูกต้อง

5. **โหมดทดลองใช้งาน (Demo Mode):**
   - หากเปิดไฟล์ขึ้นมาโดยที่ยังไม่ได้ใส่ Firebase Config ระบบจะสลับเข้าสู่โหมด Demo ให้ทดลองใช้งานฟีเจอร์ต่างๆ ได้ทันที

## 🚀 ขั้นตอนการตั้งค่า Firebase (ใช้เวลาเพียง 3-5 นาที)

เพื่อให้ระบบ Real-time ทำงานออนไลน์เต็มรูปแบบ ให้ทำตามขั้นตอนดังนี้:

### ขั้นตอนที่ 1: สร้างโปรเจกต์ใน Firebase
1. เข้าไปที่ [Firebase Console](https://console.firebase.google.com/) แล้วเข้าสู่ระบบด้วย Google Account
2. กดปุ่ม **"Add project"** (หรือสร้างโปรเจกต์)
3. ตั้งชื่อโปรเจกต์ (เช่น `harntung-app`) แล้วกดยืนยันจนสร้างเสร็จ

### ขั้นตอนที่ 2: เปิดใช้งาน Authentication (Email/Password)
1. ในแถบเมนูด้านซ้าย เลือก **Build > Authentication**
2. กดปุ่ม **Get started**
3. ในแท็บ **Sign-in method** ให้เลือก **Email/Password**
4. เปิดสวิตช์ **Enable** อันแรก (Email/Password) แล้วกด **Save**

### ขั้นตอนที่ 3: เปิดใช้งาน Cloud Firestore
1. ในแถบเมนูด้านซ้าย เลือก **Build > Firestore Database**
2. กดปุ่ม **Create database**
3. เลือก Location (แนะนำ `asia-southeast1` หรือใกล้เคียง) แล้วกด Next
4. เลือก **Start in test mode** หรือเข้าไปแก้ไขที่แท็บ **Rules** ให้เป็นดังนี้:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // ผู้ใช้ที่ล็อกอินแล้วสามารถอ่าน/เขียนข้อมูลได้
    match /users/{userId} {
      allow read, write: if request.auth != null;
    }
    match /trips/{tripId} {
      allow read, write: if request.auth != null;
    }
  }
}
```
5. กดปุ่ม **Publish**

### ขั้นตอนที่ 4: คัดลอก Firebase Config มาใส่ใน `index.html`
1. ไปที่รูปฟันเฟือง ⚙️ ด้านซ้ายบน เลือก **Project settings**
2. เลื่อนลงมาด้านล่างสุดในหัวข้อ **"Your apps"** กดไอคอน Web `</>`
3. ตั้งชื่อ App (เช่น `Harntung Web`) แล้วกด **Register app**
4. คุณจะเห็นโค้ด `firebaseConfig` ให้คัดลอกข้อมูลข้างในมาวางแทนที่ในไฟล์ `index.html` (ประมาณบรรทัดที่ 618):

```javascript
// =========================================================================
// 🔧 ตั้งค่า FIREBASE CONFIGURATION ตรงนี้
// =========================================================================
const firebaseConfig = {
    apiKey: "AIzaSy...",
    authDomain: "your-project-id.firebaseapp.com",
    projectId: "your-project-id",
    storageBucket: "your-project-id.appspot.com",
    messagingSenderId: "123456789...",
    appId: "1:123456789:web:..."
};
```

## 🧪 วิธีทดสอบการทำงานแบบ Real-time

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์ปกติ แล้วสมัครสมาชิกด้วยอีเมลแรก (เช่น `user1@gmail.com`)
2. เปิดเบราว์เซอร์อีกหน้าต่างหนึ่งใน **โหมดไม่ระบุตัวตน (Incognito)** หรือเบราว์เซอร์อื่น (เช่น Chrome กับ Edge) แล้วสมัครสมาชิกด้วยอีเมลที่สอง (เช่น `user2@gmail.com`)
3. จากหน้าต่างแรก ให้ไปที่แท็บ **1. รายชื่อเพื่อน** แล้วกรอกอีเมล `user2@gmail.com` เพื่อเชิญเข้าทริป
4. สังเกตที่หน้าต่างที่สอง ทริปจะปรากฏในรายการของ `user2` ทันที และเมื่อมีการเพิ่มค่าใช้จ่าย แก้ไขโน้ต หรืออัปโหลด QR Code ทั้งสองหน้าต่างจะอัปเดตพร้อมกันแบบเรียลไทม์! 🎉
